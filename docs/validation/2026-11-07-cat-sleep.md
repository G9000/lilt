# Small sleeping movements

Verified on Windows on 7 November 2026. All five room cats share a soft 4.8-second breath,
an occasional slow stretch and a tiny double settling twitch in a quiet 23-second cycle.
The complete cutout stays anchored to the blanket at y846 without rotation. The silhouette
outline uses the same scale. Reduced motion holds a neutral pose and clears decorative hearts.
