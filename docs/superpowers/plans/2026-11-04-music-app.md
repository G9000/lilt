# Music app and compact player

User approved replacing the oversized music popover with a proper Music app and a
compact top-bar player. Keep the painted cassette as its room entry.

- Music opens as an app window, with an expand/restore control, record artwork,
  current selection, transport/volume controls and a browsable mood list.
- Close returns to the prior view; playback continues. The top bar shows the current
  selection, play/pause and a way to reopen Music, including while paused.
- Reuse the shared lo-fi engine and existing Spotify integration. Keep one Spotify
  host mounted across navigation/expansion so playback survives closing the app.
- Keep microphone ducking, no autoplay on opening, mobile/dark/reduced-motion support,
  accessible labels and keyboard closing. Preserve camera and microphone room actions.
- Verify using isolated browser/API stubs: navigation, selection, playback, volume,
  close/reopen persistence, mini player, expansion, mic ducking and responsive fit.
  Update guide/design/release/validation and run project checks before local commit.
