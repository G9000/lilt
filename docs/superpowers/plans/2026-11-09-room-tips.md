# Room tips implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review this plan.

**Goal:** Explain room actions with hover/focus tooltips and a dismissible first-visit hint, as approved in chat.

**Architecture:** A room help component renders outside the scaled painting. Painted targets supply their own tip text; delegated pointer and focus events show one accessible, viewport-clamped tooltip. A browser-local dismissal flag and a room event support the first-visit hint and Show room tips in Make it yours. No modal tour, automatic focus on first visit, or changes to click/hold actions.

**Tech stack:** Existing React, TypeScript, Tailwind, isolated Vite and Playwright Chrome.

## Approved design

The hint says “This room is yours. Click things to use them; hold to change their look.” Touch uses Tap and mentions room shortcuts. Got it dismisses it persistently; Show room tips reopens it with keyboard focus and returns focus to Make it yours when dismissed. Storage failure still allows dismissal for this visit. It waits for decoded artwork and the settled camera and hides inside the desk. Tooltips describe actual click/hold behavior, including cat petting and artwork-only targets; keyboard copy describes Enter and available picker controls. Escape dismisses tips. The hint is nonblocking and compact on phones. Existing monitor screen entry remains intact.
