# Tea break implementation plan

**Goal:** Add the approved quiet tea timer to the room, with a choice of mugs.

**Design:** A small illustrated mug opens a compact tray with 3, 5 and 10 minute choices and four mugs (cream stoneware, sage, blue stripes and sleepy cat). Starting a break closes the tray. Steam moves while time remains; completion settles the steam and says “Whenever you're ready.” Stop clears a break without judgement. An optional soft clink defaults off and only plays in the focused room, never during recording. No automatic navigation. The mug and deadline stay in this browser. Reset layout restores its position without cancelling the timer. Like existing floating widgets, it hides at phone widths.

**Architecture:** Keep deadline parsing and remaining-time calculation in `web/src/room/tea.ts`, covered by Node tests. `web/src/room/TeaBreak.tsx` owns presentation, persistence and a cleaned-up interval plus focus/visibility/storage listeners. Use the existing draggable room wrapper, a portal dialog for controls that cannot be clipped by the painting, Tailwind utilities, inline SVG mug artwork and centralized steam keyframes. Existing widget homes stay unchanged. No server or practice-data changes.

**Tech stack:** React 18, TypeScript, Tailwind, existing Motion drag wrapper and Playwright browser fixtures.
