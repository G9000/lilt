# Painted desk mugs

Generated on 7 November 2026 using the built-in OpenAI image generation tool (not API CLI).
The final prompt set is in [prompts.json](prompts.json).

- `clear-day.png`, `clear-morning.png`, `clear-sunset.png`, `clear-night.png`: edits of Lilt's
  corresponding `room-*-v3.webp` background, removing only the small tea mug left of the keyboard.
  The app uses a small feathered repair region; the rest of each original room remains visible.
- `cream.png`: cream speckled stoneware, with a blossom motif carried through from the reference.
- `sage.png`: sage ceramic with an ivory botanical motif.
- `blue.png`: warm white ceramic with dusty blue stripes.
- `cat.png`: blush ceramic with a sleepy cat face.

The room painting is the style/perspective reference for the four cutouts. These are shaded
2D transparent PNGs; background alpha was checked. Files retain generated alpha and dimensions.
Lighting and steam are added by the app. The original generated files were copied into this
folder unchanged; no API fallback or image conversion was used.
